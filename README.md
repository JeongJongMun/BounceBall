## 소개

혀를 낼름거리는 카멜레온이 **쉬지 않고 통통 튀는** 2D 플랫포머입니다.

점프 버튼은 없습니다. 착지하면 알아서 튀어 오르니까요. 플레이어가 하는 건 **좌우 방향을 정하는 것**뿐입니다. 단순한 조작 위에, 캐릭터의 **성질**이 바뀌면 같은 발판이 전혀 다르게 반응하는 규칙을 얹었습니다.

## 조작

| | 키보드 | 터치 |
|---|---|---|
| 이동 | `A` `D` 또는 `←` `→` | 화면 왼쪽 / 오른쪽 절반 |
| 아이템 사용 | `1` ~ `3` | 퀵슬롯 탭 |
| 인벤토리 | `I` | 가방 버튼 |
| 상점 | `P` | 상점 버튼 |
| 일시정지 | `Esc` | 일시정지 버튼 |

## 성질 시스템

캐릭터는 세 가지 성질을 오갑니다. **성질 × 발판**의 조합이 결과를 정합니다.

|  | 기본 발판 | 젤리 발판 | 얼음 발판 |
|---|---|---|---|
| **기본** | 보통 점프 | 낮은 점프 | 낮은 점프 |
| **젤리** | 높은 점프 | **표면에 달라붙어 기어다님** | 보통 점프 |
| **얼음** | 낮은 점프 | 보통 점프 | **점프 없이 미끄러짐** |

젤리로 벽과 천장을 타고, 얼음으로 관성을 이용해 미끄러지는 식으로 길을 엽니다.
