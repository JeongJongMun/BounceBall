# Game — 스테이지 제작 가이드 (아트/기획용)

카멜레온 바운스의 스테이지를 만드는 방법입니다. 코드를 몰라도 됩니다.

---

## 1. 셋업 — 필요 없습니다

타일, 팔레트, 아이템 프리팹, 브러시는 전부 레포에 포함되어 있습니다. 받자마자 바로 스테이지를 만들 수 있어요.
(에셋을 실수로 지웠다면 git으로 복구하거나 개발자에게 알려주세요)

---

## 2. 새 스테이지 만들기

1. 메뉴 **`Game > New Stage...`** → 저장 위치 선택 (`Assets/Game/Scenes/Stages/`)
2. 씬에 자동으로 만들어지는 것들:

| 오브젝트 | 용도 |
|---|---|
| `Grid/Ground` | **바닥 타일** 레이어 — 충돌이 자동 생성됩니다 |
| `Grid/Deco` | **배경 장식** 레이어 — 충돌 없음 |
| `Gimmicks` | 아이템·체크포인트가 담기는 컨테이너 (자동 관리, 손댈 필요 없음) |
| `Stage` | 스테이지 설정 + 시작 위치(`StartPosition`) |

시작용 바닥 타일 한 줄도 같이 깔립니다.

씬을 저장하면 **메인 메뉴의 스테이지 버튼과 빌드 목록에 자동으로 반영됩니다** — 별도 등록 작업이 없습니다. (씬 삭제·이름 변경도 자동 반영)

---

## 3. 배치하기 — 타일이든 아이템이든 전부 팔레트에서

### ⚠️ 최초 1회: 브러시를 반드시 바꾸세요

**Tile Palette** 창 상단의 브러시 드롭다운이 기본값 **"Default Brush"**로 되어 있습니다.
이걸 **"StageBrush"**로 바꿔주세요. 한 번 바꾸면 계속 유지됩니다.

> **안 바꾸면 아이템이 조용히 망가집니다.** 기본 브러시로 칠하면 색깔 점은 똑같이 찍히는데 실제 프리팹이 생성되지 않아서, 게임에서 아무 동작도 하지 않는 **장식 타일**만 남습니다.
> 아이템에 다가가도 `E`가 안 뜨거나, 목표 아이템을 먹어도 카운터가 안 오르면 십중팔구 이 경우입니다.
> 다행히 **스테이지 검증**(6번)을 누르면 이렇게 남은 마커 타일을 찾아서 **실제 아이템으로 자동 변환**해 줍니다. 그래도 브러시는 바꿔 쓰는 게 좋습니다.

### 팔레트 열기

**Window > 2D > Tile Palette** → 팔레트 드롭다운에서 **StagePalette** 선택

### 팔레트 구성

칸이 **두 줄**로 나뉘어 있습니다. Unity 팔레트는 위쪽이 y가 큰 줄이라, **오브젝트가 윗줄, 타일이 아랫줄**입니다.

**윗줄 — 오브젝트** (프리팹으로 스폰됨)

| 색 | 항목 | 동작 |
|---|---|---|
| 초록 | 기본 성질 아이템 | 가까이 가서 `E` → 기본 성질로 |
| 보라 | 젤리 성질 아이템 | 가까이 가서 `E` → 젤리 성질로 |
| 하늘 | 얼음 성질 아이템 | 가까이 가서 `E` → 얼음 성질로 |
| 노랑 | 목표 아이템 | **닿으면 자동 획득** (`E` 불필요) |
| 분홍 | 체크포인트 | 스치면 활성화, **흰색으로 변함** |

**아랫줄 — 타일** (타일맵에 그려짐)

| 색 | 항목 |
|---|---|
| 회색 | 기본 타일 |
| 보라 | 젤리 타일 |
| 하늘 | 얼음 타일 |

> 타일과 성질 아이템의 색이 짝을 이룹니다 — 보라 타일은 보라(젤리) 성질과, 하늘 타일은 하늘(얼음) 성질과 반응합니다.

### 그리기

- **B** 브러시로 그리기
- **D** 지우개로 지우기 (그 칸의 타일과 오브젝트를 **둘 다** 지웁니다)
- **U** 사각형으로 영역 채우기

오브젝트에도 똑같이 동작합니다. 브러시를 바꿔 낄 필요가 없습니다.

### 어디에 그려지나

- **타일**은 현재 선택된 타일맵에 그려집니다. 바닥은 **`Grid/Ground`**, 배경 장식은 **`Grid/Deco`**를 선택하고 그리세요 (Deco는 충돌이 없습니다)
- **오브젝트**는 타일맵에 남지 않고, 프리팹이 칸 중앙에 스폰되어 **`Gimmicks`** 아래로 정리됩니다 (칸당 1개)

## 4. 점프는 성질 × 타일 조합으로 결정됩니다

점프력을 타일이나 아이템에 개별로 넣지 않습니다. **공용 3값(감소/일반/증가)** 중 하나가 조합에 따라 자동으로 골라집니다:

| 플레이어 \ 타일 | 기본 | 젤리 | 얼음 |
|---|---|---|---|
| **기본** | 일반 | 낮게 | 낮게 |
| **젤리** | **높게** | 부착 (안 튐) | 일반 |
| **얼음** | 낮게 | 일반 | 미끄러짐 |

이걸 이용해 "젤리 성질이어야 넘을 수 있는 높은 벽", "기본 성질로는 못 넘는 구간" 같은 설계를 할 수 있습니다.

수치를 바꾸려면 `Resources/Player.prefab`의 **PlayerStats**에서 공용 점프 3값을 조정하세요.

> 현재 **젤리 부착의 표면 이동(벽·천장)과 얼음 미끄러짐은 아직 미구현**입니다. 점프 결과만 적용되고, 젤리×젤리는 "튀지 않고 멈춤"까지만 동작합니다.

---

## 5. 체크포인트와 사망

- 체크포인트는 **굳이 배치하지 않아도 됩니다.** 없으면 시작 위치가 부활 지점입니다
- 나중에 밟은 체크포인트가 항상 이전 것을 대체합니다
- 밟은 **시점의 성질과 목표 아이템 획득 상태**가 저장됩니다. 그 이후에 먹은 목표 아이템은 죽으면 되살아납니다
- **목표 아이템과 1칸 이상 띄우세요** — 부활 지점이 아이템과 겹치면 되살아나자마자 다시 먹힙니다

사망 조건: 좌·우 경계를 넘거나 낙사선 아래로 떨어지면 부활합니다.
**위쪽은 아무리 높이 올라가도 죽지 않습니다** (세로로 긴 스테이지 대응)

## 6. 스테이지 설정 (`Stage` 오브젝트 선택)

- **경계 자동 계산**: 그려둔 Ground 타일 범위로 카메라 경계와 낙사선을 자동 설정
  - 씬 뷰 표시: 하늘색 사각형 = 카메라 경계, 빨간 선 = 낙사선, 초록 원 = 시작 위치
  - **하늘색 사각형의 좌우 변은 사망선이기도 합니다**
- **RequiredGoalItemCount**: 클리어에 필요한 목표 아이템 수 — 직접 입력합니다. 이 수량을 채우면 화면 상단 카운터가 `3 / 3`이 되면서 플레이어가 멈추고 클리어 화면이 뜹니다 (다음 스테이지가 있으면 **Next Stage** 버튼도 함께)
- **스테이지 검증**: 시작 위치, 목표 아이템 수량, 낙사선 아래 배치물, 이벤트 채널 배선을 검사해 콘솔에 출력합니다. **잘못 칠해진 마커 타일은 발견 즉시 실제 아이템으로 자동 변환**합니다. 저장 전에 한 번씩 눌러주세요 (콘솔 메시지를 클릭하면 해당 오브젝트가 선택됩니다)

---

## 7. 새 항목 등록하기

- **새 타일 스프라이트** → 팔레트 창에 드래그
- **새 성질 타일** → Create > **Game > Special Tile** 생성 후, 인스펙터에서 `Tile Property`(기본/젤리/얼음)를 고르고 팔레트에 드래그
- **새 기믹 프리팹** → Create > **Game > Prefab Marker Tile** 생성 → `Prefab` 칸에 프리팹 연결 → 팔레트에 드래그
