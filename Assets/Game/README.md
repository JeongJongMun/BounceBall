# Game — 스테이지 제작 가이드 (아트/기획용)

카멜레온 바운스의 스테이지를 만드는 방법입니다. 코드를 몰라도 됩니다.

## 최초 1회 셋업

메뉴 **`Game > Setup Stage Tooling`** 실행 → 타일, 팔레트, 아이템 프리팹, 브러시가 생성됩니다.
(이미 에셋이 있으면 다시 실행해도 덮어쓰지 않습니다)

## 새 스테이지 만들기

1. 메뉴 **`Game > New Stage...`** → 저장 위치 선택 (`Assets/Game/Scenes/Stages/`)
2. 씬에 자동으로 만들어지는 것들:
   - `Grid/Ground` — 바닥 타일을 그리는 레이어 (충돌 자동 생성)
   - `Grid/Deco` — 배경 장식 레이어 (충돌 없음)
   - `Gimmicks` — 아이템/기믹이 배치되는 컨테이너 (자동 관리)
   - `Stage` — 스테이지 설정 + 시작 위치(`StartPosition`)
   - 시작용 바닥 타일 한 줄

## 타일 그리기 (기본 발판)

1. **Window > 2D > Tile Palette** 창 열기
2. 팔레트 드롭다운에서 **StagePalette** 선택
3. Hierarchy에서 **Grid/Ground** 가 액티브 타일맵인지 확인
4. 브러시(B)로 그리기, 지우개(D)로 지우기, 사각형(U)으로 영역 채우기
- 새 타일 스프라이트가 생기면 팔레트 창에 드래그해서 등록하면 됩니다
- 장식은 **Grid/Deco** 레이어에 그리세요 (충돌 없음)

## 아이템/기믹 배치 (프리팹 브러시)

1. Tile Palette 창 상단의 **브러시 드롭다운** (기본값 "Default Brush") 클릭
2. **Prefab Brush** 선택 → 프로젝트의 `Assets/Game/Tiles/Brushes/`에서 원하는 브러시 에셋 선택
   - `PropertyItemBrush` — 성질 아이템 (보라)
   - `GoalItemBrush` — 목표 아이템 (노랑)
   - `CheckpointBrush` — 체크포인트 (초록)
3. 씬에서 원하는 셀 클릭 → 프리팹이 셀 중앙에 배치됩니다
- 한 셀에는 하나만 배치됩니다
- 지우개(D)로 배치물 삭제
- 배치물은 자동으로 `Gimmicks` 아래에 정리됩니다
- 새 기믹 프리팹이 생기면: 프로젝트 창 우클릭 > Create > **Game > Prefab Brush** 로 브러시를 만들고 prefab 칸에 프리팹을 연결하세요

## 스테이지 설정 (Stage 오브젝트 선택)

- **경계 자동 계산**: 그려둔 Ground 타일 범위로 카메라 경계와 낙사선을 자동 설정 (씬 뷰에 하늘색 사각형 = 카메라 경계, 빨간 선 = 낙사선, 초록 원 = 시작 위치)
- **RequiredGoalItemCount**: 클리어에 필요한 목표 아이템 수 — 직접 입력
- **스테이지 검증**: 시작 위치, 목표 아이템 수량, 낙사선 아래 배치물 등을 검사해서 콘솔에 결과 출력. 저장 전에 한 번씩 눌러주세요

## 주의

- 타일을 수정한 뒤에는 **경계 자동 계산**을 다시 눌러주세요
- 아이템을 손으로 움직였다면 셀 중앙에서 벗어날 수 있습니다 — 웬만하면 브러시로만 배치/삭제하세요
