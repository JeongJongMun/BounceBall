# Game — 스테이지 제작 가이드 (아트/기획용)

카멜레온 바운스의 스테이지를 만드는 방법입니다. 코드를 몰라도 됩니다.

## 최초 1회 셋업

메뉴 **`Game > Setup Stage Tooling`** 실행 → 타일, 팔레트, 아이템 프리팹, 브러시가 생성됩니다.
(이미 에셋이 있으면 다시 실행해도 덮어쓰지 않습니다)

## 새 스테이지 만들기

1. 메뉴 **`Game > New Stage...`** → 저장 위치 선택 (`Assets/Game/Scenes/Stages/`)
2. 씬에 자동으로 만들어지는 것들:
   - `Grid/Ground` — 바닥 타일을 그리는 레이어 (충돌 자동 생성)
   - `Grid/Deco` — 배경 장식 레이어 (충돌 없음)
   - `Gimmicks` — 아이템/기믹이 배치되는 컨테이너 (자동 관리)
   - `Stage` — 스테이지 설정 + 시작 위치(`StartPosition`)
   - 시작용 바닥 타일 한 줄

## 배치하기 (타일이든 아이템이든 전부 팔레트에서)

**최초 1회**: Tile Palette 창 상단의 브러시 드롭다운(기본값 "Default Brush")에서 **Stage Brush**를 선택해두세요. 이후에는 계속 유지됩니다.

1. **Window > 2D > Tile Palette** 창 열기 → 팔레트 드롭다운에서 **StagePalette** 선택
2. 팔레트에서 원하는 것을 골라 씬에 그리면 끝 — 브러시 전환 없이 전부 배치됩니다:
   - **1행 — 타일**: 회색 = 일반 발판, 주황 = 바운시 타일(1.6배 점프, 특수 타일 예시)
   - **2행 — 오브젝트**: 보라 = 성질 아이템, 노랑 = 목표 아이템, 초록 = 체크포인트
3. 브러시(B) 그리기, 지우개(D) 지우기, 사각형(U) 영역 채우기 — 오브젝트에도 동일하게 동작

동작 방식:
- 타일은 액티브 타일맵(**Grid/Ground**)에 그려지고, 장식은 **Grid/Deco**에 그리세요 (충돌 없음)
- 오브젝트(2행)는 타일맵에 남지 않고 프리팹이 셀 중앙에 스폰되어 `Gimmicks` 아래 정리됩니다 (셀당 1개)
- 지우개는 그 셀의 타일과 오브젝트를 모두 지웁니다

새 항목 등록:
- 새 타일 스프라이트 → 팔레트 창에 드래그
- 새 특수 타일 → Create > **Game > Special Tile** 생성 후 팔레트에 드래그 (성질별 반응은 인스펙터에서 설정)
- 새 기믹 프리팹 → Create > **Game > Prefab Marker Tile** 생성, prefab 연결 후 팔레트에 드래그

## 스테이지 설정 (Stage 오브젝트 선택)

- **경계 자동 계산**: 그려둔 Ground 타일 범위로 카메라 경계와 낙사선을 자동 설정 (씬 뷰에 하늘색 사각형 = 카메라 경계, 빨간 선 = 낙사선, 초록 원 = 시작 위치)
- **RequiredGoalItemCount**: 클리어에 필요한 목표 아이템 수 — 직접 입력
- **스테이지 검증**: 시작 위치, 목표 아이템 수량, 낙사선 아래 배치물 등을 검사해서 콘솔에 결과 출력. 저장 전에 한 번씩 눌러주세요

## 주의

- 타일을 수정한 뒤에는 **경계 자동 계산**을 다시 눌러주세요
- 아이템을 손으로 움직였다면 셀 중앙에서 벗어날 수 있습니다 — 웬만하면 브러시로만 배치/삭제하세요
