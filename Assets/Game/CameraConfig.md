# 카메라 · 투명 벽 설정 가이드 (기획용)

카메라 값은 **두 곳**에 나뉘어 있습니다.

| | 어디에 있나 | 무엇을 담나 |
|---|---|---|
| **글로벌** | `Assets/Game/Resources/CameraSettings.asset` | 게임 전체 공통 **조작감**. 스테이지마다 다르면 어색한 값 |
| **스테이지별** | 스테이지 씬의 `Stage` 오브젝트 인스펙터 | 맵 생김새에 따라 달라지는 **프레이밍**과 **투명 벽** |

> 판단 기준: *"스테이지마다 달라지면 플레이어가 어색해하는가?"* — 어색하면 글로벌, 아니면 스테이지별.

---

## 1. 글로벌 — CameraSettings.asset

프로젝트 창에서 `Assets/Game/Resources/CameraSettings.asset`을 선택하면 인스펙터에 나옵니다.

### 데드존 (화면 절반 대비 비율)

카메라가 **따라가지 않는 안전 구역**입니다. 캐릭터가 이 안에서 움직이는 동안 화면은 가만히 있습니다.

| 값 | 기본 | 설명 |
|---|---|---|
| **가로 데드존** | 0.33 | 좌우 기준. **키우면** 많이 움직여도 화면이 고정돼 안정적이고, **줄이면** 조금만 움직여도 바로 따라와 반응이 빠릅니다 |
| **세로 데드존** | 0.33 | 위아래 기준. **점프할 때 화면이 출렁이면 이 값을 키우세요** |

> **알아두실 점**: 현재 기본값(0.33)은 점프 정점보다 살짝 작아서, 평지에서 자동 바운스할 때마다 화면이 미세하게 위아래로 움직입니다. 0.5 정도로 올리면 사라집니다. 기존 감각을 유지하려고 기본값은 그대로 뒀으니, 직접 올려가며 맞춰보세요.

### 추적 속도 (초)

목표 위치까지 따라붙는 데 걸리는 시간입니다. **작을수록 빠릿**하고, 클수록 여유롭게 따라옵니다.

| 값 | 기본 | 설명 |
|---|---|---|
| **가로 추적 속도** | 0.15 | 좌우로 따라붙는 속도 |
| **세로 추적 속도** | 0.15 | 위아래로 따라붙는 속도. 보통 **세로를 조금 느리게** 하면 점프가 부드러워 보입니다 |

### 기타

| 값 | 기본 | 설명 |
|---|---|---|
| **부활 시 즉시 이동** | 켜짐 | 죽고 되살아날 때 카메라가 순간이동합니다. 끄면 맵을 가로질러 스윽 날아갑니다 |
| **데드존 표시** | 켜짐 | 씬 화면에 데드존을 **노란 사각형**으로 그립니다. 값을 바꿔가며 눈으로 확인할 때 쓰세요. 빌드에는 영향이 없습니다 |

## 2. 스테이지별 — Stage 오브젝트

스테이지 씬에서 `Stage` 오브젝트를 선택하면 나옵니다.

### 카메라 (이 스테이지 전용)

| 값 | 기본 | 설명 |
|---|---|---|
| **카메라 크기(줌)** | 5 | 화면에 얼마나 넓게 보일지. **세로 절반 크기** 기준이라 5면 위아래로 10칸이 보입니다. 넓은 맵은 키우고, 아기자기한 맵은 줄이세요 |
| **세로 오프셋** | 0 | 캐릭터를 화면 정중앙이 아닌 곳에 두기. **값을 올리면 캐릭터가 화면 아래쪽에 놓여 위쪽이 더 보입니다** — 위로 올라가는 스테이지에 유용 |
| **가로 추적 잠금** | 꺼짐 | 켜면 카메라가 **좌우로 안 움직입니다**. 한 화면에 다 들어오는 맵, 세로 전용 맵에 사용 |
| **세로 추적 잠금** | 꺼짐 | 켜면 카메라가 **위아래로 안 움직입니다**. 가로로만 진행하는 평지 맵에 쓰면 화면이 완전히 안정적입니다 |
| **카메라 설정 덮어쓰기** | 비움 | 이 스테이지만 조작감을 다르게 하고 싶을 때 다른 설정 에셋을 넣습니다. **평소엔 비워두세요** (비우면 글로벌 설정 사용) |

> 축을 잠그면 그 방향으로는 **스테이지 한가운데**에 고정됩니다.

### 경계 여백

| 값 | 기본 | 설명 |
|---|---|---|
| **Bounds Padding** | 3 | 타일 끝에서 카메라가 얼마나 더 빈 공간을 보여주고 멈출지. **타일을 수정한 뒤에는 [경계 자동 계산] 버튼을 다시 누르세요** |

### 투명 벽

플레이어가 화면 밖으로 나가지 못하게 좌우를 막는 보이지 않는 벽입니다. (벽에 부딪혀도 죽지 않고 그냥 막힙니다)

| 값 | 기본 | 설명 |
|---|---|---|
| **투명 벽 사용** | 켜짐 | **끄면 플레이어가 화면 밖으로 나갈 수 있습니다.** 카메라는 경계에서 멈추므로 캐릭터가 안 보이게 됩니다 — 낙사로 유도하는 특수 연출용 |
| **벽 위치 방식** | 경계 기준 | **경계 기준**: 카메라 경계에서 자동 계산 / **직접 지정**: 좌우 X 좌표를 손으로 입력 |
| **경계에서 벌리기** | 0 | *(경계 기준)* 벽을 경계선보다 얼마나 더 바깥에 세울지. **0이면 화면 끝까지** 갈 수 있고, 키우면 화면 끝에 닿기 전에 막힙니다. **음수면 화면 안쪽에서** 막힙니다 |
| **왼쪽 / 오른쪽 벽 X** | ∓12 | *(직접 지정)* 각 벽의 X 좌표. 좌우를 비대칭으로 두고 싶을 때 |
| **벽 높이 여유** | 30 | 낙사선부터 위로 얼마나 높게 세울지. **세로로 긴 스테이지에서 위로 빠져나가면** 키우세요 |

## 3. 씬 화면에서 확인하기

`Stage` 오브젝트를 선택하면 씬 뷰에 표시됩니다.

| 색 | 의미 |
|---|---|
| 🟦 하늘색 사각형 | 카메라 경계 (이 밖은 화면에 안 보임) |
| 🟪 보라색 세로선 | 투명 벽 (플레이어가 닿는 면) |
| 🟥 빨간 가로선 | 낙사선 (아래로 떨어지면 부활) |
| 🟩 초록 원 | 시작 위치 |
| 🟨 노란 사각형 | 데드존 *(Main Camera 선택 시)* |

## 4. 자주 겪는 상황

**"점프할 때마다 화면이 흔들려요"**
→ 글로벌 **세로 데드존**을 키우세요 (0.33 → 0.5)

**"카메라가 너무 늦게 따라와요"**
→ 글로벌 **추적 속도**를 줄이세요 (0.15 → 0.08)

**"맵이 커서 답답해요"**
→ 스테이지 **카메라 크기(줌)**를 키우세요 (5 → 7)

**"위로 올라가는 맵인데 발밑만 보여요"**
→ 스테이지 **세로 오프셋**을 올리세요 (0 → 2)

**"타일을 넓혔는데 못 가는 구간이 생겼어요"**
→ `Stage`의 **[경계 자동 계산]** 버튼을 다시 누르세요

**"평지인데 화면이 계속 미세하게 움직여요"**
→ 스테이지 **세로 추적 잠금**을 켜세요

**"저장 전에 확인하고 싶어요"**
→ `Stage`의 **[스테이지 검증]** 버튼. 벽 바깥에 놓인 아이템, 낙사선 아래 배치물 등을 잡아줍니다
